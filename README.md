# Nathaniel Bubis’s blog

Source for [nbubis.github.io](https://nbubis.github.io), built with the [Chirpy Jekyll theme](https://github.com/cotes2020/jekyll-theme-chirpy) and its [official starter](https://github.com/cotes2020/chirpy-starter).

## Local development

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

GitHub Actions builds and deploys the site from `master` to GitHub Pages. In repository Settings → Pages, set the source to **GitHub Actions**.
